Action Taxonomy 1.1 (`TAXONOMY_VERSION` is now `1.1`). New types for what a coding agent reaches through cloud, Kubernetes, database, deployment, secret, messaging and tracker tools: `cloud.resource.create`, `cloud.resource.modify` and `cloud.resource.delete` (`provider` aws, gcp, azure, cloudflare, vercel, fly, heroku, github or unknown; `service`, `kind`, `region`, `env`, `resource_digest`, `auto_approve`, `targeted`), `k8s.apply`, `k8s.delete` and `k8s.exec` (`context`, `namespace`, `kind`, `name_digest`, `all`), `db.migrate` (`provider`, `direction` up, down or reset, `env`, `migration_set_digest`), `db.exec` (`provider`, `verb`, `scope`, `risk`, `predicate_class`), `secret.write` (`store`, `name_digest`, `env`), `iam.change` (`provider`, `kind` role, policy, user, key, group or other, `name_digest`, `env`), `communication.send` (`provider`, `channel_digest`) and `work.item.create` / `work.item.update` (`provider`, `project_digest`). Every new type also takes `via`, `derived_from` and `risk_class`. Risk classes: deletes, `k8s.delete`, `k8s.exec` and `db.migrate` destructive, `iam.change` identity, `work.item.*` routine, the rest sensitive. The 1.0 types are unchanged; each action now carries the taxonomy version that introduced it (`1.0` or `1.1`). `vectors/action-taxonomy.json` has valid and invalid cases for every new type.
