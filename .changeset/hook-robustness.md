Robustness. Secret scrubbing reads a header value once: a 100 kB run of `name:name:…` took seconds and now takes milliseconds. A hook call that has not decided shortly before the coding agent's own hook time limit (55 s for Claude Code, 45 s for GitHub Copilot, 28 s for Codex and Cursor) now denies instead of being left to time out, which an agent treats as "run it"; `SCOPEBOND_HOOK_DEADLINE_MS` can only shorten the deadline. The person's wait in the Scopebond window shrinks to what the deadline leaves, a hook call waits at most 8 s for the local log's lock (2 s for the observation log), and the single executable now fails closed on a crash too. Trusted projects are keyed by their canonical path, so a project reached through a link (or macOS's `/var` and `/private/var`) is one project; pins written before are still read. A bypass corpus (`test/bypass-corpus/`) records what the hook blocks or names for indirect forms of blocked actions, and its known gaps. Every call to the workspace (sign-in and enrollment, rules check and confirmation, record delivery and summaries, observations, credential renewal, recovery, `doctor` checks, uninstall notice) now carries `x-scopebond-hook-version`.
