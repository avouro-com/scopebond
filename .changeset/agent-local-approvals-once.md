Unblocking from the Scopebond icon now allows only the next try of the blocked action on the computer itself. Any program running as you can reach the agent's local channel, including a coding agent, so an answer sent there cannot prove a person gave it. Choosing a longer unblock (15 minutes, 1 hour, until tomorrow, the workspace's number of days, or similar commands) no longer makes an allowance on the computer. Instead it sends your workspace a request that an admin approves in the web portal, and the action is allowed once in the meantime. If the computer is not connected to a workspace, only Allow once is possible. A one-time allowance made this way is marked `local_unverified` in the record sent to the workspace.
