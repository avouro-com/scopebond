On Windows, programs installed as App Execution Aliases (Store Python, `winget`, `wt`) are found on PATH again, so `scopebond-mcp -- python server.py` starts with Store Python. When a folder's own access list cannot be changed, every key, credential and evidence file in it is still restricted to its owner one by one; outside a private folder each file is restricted once rather than on every start. Evidence scrubbing masks only the secret: text after a quote that closes an earlier string, or after `;NAME=value`, stays in the record.
