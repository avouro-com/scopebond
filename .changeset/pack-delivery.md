Rule packs are delivered from a workspace: a rules check answer may name the packs a computer should hold, signed beside the rules, and the hook fetches each one from `/v1/packs/<id>@<version>`, checks its digest, signature and vectors, and keeps exactly the named packs (an empty list leaves none). The pack format gains grammar options for reading a command line the way a tool does (`path_options`, `strict_unknown`, `fallback_on_any_option`, `fallback_only_unread`, `double_dash`), the `unknown_option` condition and `positionals` past an unknown option. The first MCP profile whose words name a server owns its calls. `setBuiltinReaders` turns the built-in readers off for parity checks, `decomposeShell` is exported, and the built-in readers find tools through the shared launcher reader.
